## 🚀 How to Run Locally

You can open `index.html` directly in any web browser (double-click `index.html`).

Or run a local development server using Python:

```bash
python -m http.server 8080
```

Then visit [http://localhost:8080](http://localhost:8080) in your browser.

## 🌐 Free 1-Click Hosting Options

1. **GitHub Pages:**
   - Push this folder to a GitHub repository named `jayparmar.github.io` (or any repository name).
   - Go to **Settings > Pages > Source** and select `main` branch.
2. **Netlify:**
   - Drag and drop this folder directly into [app.netlify.com/drop](https://app.netlify.com/drop) for instant deployment in 10 seconds.
3. **Vercel:**
   - Deploy directly with `vercel` CLI or import the GitHub repository on [vercel.com](https://vercel.com).
